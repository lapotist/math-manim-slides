# Carlo Permission Scope

Status: permission recorded for reference-based Manim adaptations and public
open-source publication.

The maintainer reports that on 2026-07-24 they asked the owner of 正哥愛數學
for permission to use videos from the channel as references, generate Manim
visualizations of problems, and publish the generated work on GitHub under
CC0 or a license requiring attribution. The owner agreed and asked that the
finished work be shared afterward.

The repository records that scope without publishing the private message,
account details, or other correspondence. For this project, the selected
attribution license is CC BY 4.0 for project-authored educational content;
project software uses MIT. Completed work should be shared with the owner after
the public repository is available, as requested.

This permission supports using the channel videos as research references and
publishing the independently generated Manim adaptations. It does not state
that the owner transfers ownership of, or applies CC BY 4.0 to, the source
videos. It also does not establish authority over school questions, exam PDFs,
logos, fonts, publisher material, student work, or any other third-party item.
Those inputs remain excluded under `NOTICE.md` unless a separate record proves
otherwise.

The project therefore links to sources, reconstructs the mathematics and
visuals independently, and does not redistribute source scans, frames, audio,
branding, or copied diagrams. Source credit in `SOURCES.md` is a provenance
record, not a claim that a source itself uses the project's licenses.
