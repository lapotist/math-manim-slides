# Project Rename Record: 2026-07-25

The umbrella project and public repository were renamed to **Math Manim
Slides** and `math-manim-slides` so lessons researched from different sources
can coexist without implying that Carlo is the source of every lesson.

- Current URL: <https://github.com/lapotist/math-manim-slides>
- Former URL: <https://github.com/lapotist/carlo-math-manim-slides>
- License model: unchanged MIT / CC BY 4.0 path-based split
- Carlo lesson IDs, source credits, permission records, and solution locators:
  unchanged

GitHub redirects the former repository URL to the current URL. The former name
must not be reused for a different repository because that would break the
redirect.

The neutral `math_manim` import API is canonical for new lessons. Existing
human-reviewed decks keep their `carlo_manim` imports and the locked editable
distribution identifier until a future migration rerenders and visually
reviews all affected lessons. This compatibility boundary preserves the
meaning of the committed QA attestations; it does not make Carlo the umbrella
project identity or content licensor.
